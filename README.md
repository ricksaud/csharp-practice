# C# Practice Projects

A collection of small console projects built while learning C#, going from the basics (variables, loops, conditionals, methods) through OOP (classes, inheritance, interfaces).

Each project lives in its own numbered folder, in the order I built them.

## Projects

| # | Project | Concepts practiced |
|---|---------|---------------------|
| 01 | [Calculator](./01%20-%20Calculator) | loops, if/else, switch, methods, input validation (`TryParse`), basic error handling (divide by zero) |
| 02 | [Guess The Number](./02%20-%20Guess%20The%20Number) | nested loops, Random, TryParse, replay logic |

More projects will be added here as I complete them.

I'm learning C# from the basics up through OOP (currently working on inheritance and interfaces). This repo is where I practice writing and debugging code on my own, project by project.
