# C# Practice Projects

A collection of small console projects built while learning C#, from the fundamentals such as variables, loops, conditionals and methods to object-oriented programming with classes and objects.

Each project lives in its own numbered folder, in the order I built them.

## Projects

| # | Project | Concepts practiced |
|---|---|---|
| 01 | [Calculator](https://github.com/ricksaud/csharp-practice/blob/main/01%20-%20Calculator) | loops, if/else, switch, methods, input validation (`TryParse`), basic error handling |
| 02 | [Guess The Number](https://github.com/ricksaud/csharp-practice/blob/main/02%20-%20Guess%20The%20Number) | nested loops, `Random`, `TryParse`, replay logic |
| 03 | Password Validator | methods, `foreach`, strings, chars, booleans, validation rules, `Contains()` |
| 04 | Student Grade System | classes, objects, constructors, properties, `List<T>`, methods, `switch`, `foreach`, input validation, LINQ `Average()` |

More projects will be added as I complete them.

## About

I'm learning C# by building small projects and gradually combining the concepts I study.

This repository is where I practice writing code, solving problems, debugging, and getting more comfortable with C# and object-oriented programming.
